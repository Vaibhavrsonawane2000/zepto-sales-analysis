# zepto-sales-analysis
Zepto Sales Analysis Dashboard | Python, Power BI  • Performed exploratory data analysis on sales dataset using Python and Pandas. • Built regression model to predict revenue using pricing and order features. • Developed interactive Power BI dashboard with KPI tracking and business insights. • Analyzed revenue trends, discount impact, etc.
End-to-end Zepto Sales Analysis Project using Python, Regression Analysis, and Power BI Dashboard.

# Project overview
- Analyze sales performance
- Understand customer purchasing behavior
- Identify top-performing categories
- Measure influencer marketing impact
- Predict revenue using regression analysis

# Key Business Insight
1. Grocery category generated highest revenue.
2. Influencer marketing improved sales performance.
3. Moderate discounts increased orders.
4. Metro cities generated maximum revenue.
5. Orders strongly influenced revenue prediction.
